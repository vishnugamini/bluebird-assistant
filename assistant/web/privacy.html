Bluebird privacy policy

Updated November 17, 2026

Bluebird Assistant connects an owner-controlled Google account to a personal assistant. This page describes the default implementation. Operators should adapt it to their deployment and data-handling practices.

Google account access

With account authorization, Bluebird reads Gmail messages and calendar events to summarize email, identify conflicts, calculate free time, and deliver scheduled briefings and meeting alerts. Gmail compose permission supports drafts and sending. Application code requires explicit approval from the configured Telegram owner before sending an email and restricts recipients to the configured test mailbox. Calendar access is read-only.

Processing and recipients

The assistant runs on Google Cloud. Telegram carries messages and notifications sent through the bot. Ordinary chat and email summary prompts may be processed by OpenAI. Inference for conversations marked private uses Gemma on the owner's Mac through Tailscale. Those messages still pass through Telegram or the cloud browser gateway. Google account data is accessed only for the assistant features described here.

Storage and deletion

Conversation history, synthetic preferences, approval records, and job state are stored in the runtime and private Cloud Storage snapshots. Google credentials are stored in Secret Manager and restricted runtime files. Routing logs record model choices, timing, usage, and outcomes without message text. Data and backups remain in the deployment until the operator deletes them. To request deletion of stored data and backups, contact the project owner.

Control and contact

Account owners can revoke Bluebird's access through their Google Account third-party connections settings. Revocation stops future Google API access. Deleting data already stored by Bluebird requires a separate deletion request. Contact the operator through the support address shown on the Google consent screen for questions or deletion requests.

Bluebird's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.
